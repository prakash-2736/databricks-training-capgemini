# Day 1 - SQL String Functions Practice

## 📌 Overview

Day 1 focused on practicing SQL string functions used for text manipulation, formatting, extraction, and transformation.

This practice helped in understanding how SQL handles string operations commonly used in data cleaning, reporting, ETL workflows, and transformation tasks in Data Engineering.

The assignment included function-based queries without requiring relational tables, focusing purely on SQL built-in string operations.

## 📚 Topics Covered

### 🔹 Case Conversion Functions

Used functions for text case transformation:

- `UPPER()`
- `LOWER()`

Examples:
- Convert text to uppercase
- Convert text to lowercase
- Standardize string formatting

---

### 🔹 String Length Functions

Used:

- `LENGTH()`

Examples:
- Count characters in strings
- Calculate space occurrences
- String size analysis

---

### 🔹 Substring Extraction

Used:

- `SUBSTRING()`

Examples:
- Extract first characters
- Extract remaining text
- Extract middle names
- Partial string slicing

---

### 🔹 String Concatenation

Used:

- `CONCAT()`

Examples:
- Combine multiple strings
- Create greetings
- Build formatted text output

---

### 🔹 Space Handling Functions

Used:

- `TRIM()`

Examples:
- Remove leading spaces
- Remove trailing spaces
- Clean user-entered text

---

### 🔹 Replacement Functions

Used:

- `REPLACE()`

Examples:
- Replace old text values
- Standardize words
- Dynamic string transformation

---

### 🔹 Search Functions

Used:

- `INSTR()`

Examples:
- Find substring position
- Search keyword occurrence

---

### 🔹 Reverse Functions

Used:

- `REVERSE()`

Examples:
- Reverse string content
- Pattern manipulation

---

### 🔹 Combined Function Usage

Practiced nested function logic:

Examples:
- `UPPER()` + `CONCAT()`
- `LENGTH()` + `REPLACE()`
- `UPPER()` + `LOWER()`

This helped understand function chaining in SQL.

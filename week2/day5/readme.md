# Week 2 - Day 5: SQL NULL Functions Practice

## 📌 Overview

Week 2 Day 5 focused on practicing SQL NULL handling functions and conditional logic used for managing missing, unknown, or incomplete data.

Handling NULL values correctly is a critical SQL skill because real-world datasets often contain missing information. Proper NULL handling is essential in ETL pipelines, reporting systems, analytics workflows, and production database querying.

This assignment focused on understanding NULL behavior, replacement functions, conditional checks, counting behavior, and comparison logic.
